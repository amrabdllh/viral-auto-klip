# Font subtitle & hook

Font Google Fonts yang dipakai preset subtitle (sama dengan klipers.pro, lihat `docs/klipers-re/LAPORAN_KLIPERS.md` §12.1).
Semuanya berlisensi **SIL Open Font License 1.1** (https://openfontlicense.org) — bebas dipakai, disertakan, dan didistribusikan.

| File | Sumber |
|---|---|
| Montserrat-Regular/Bold/ExtraBold.ttf | github.com/JulietaUla/Montserrat |
| Anton, Poppins (Regular/SemiBold/Bold), Bebas Neue, Archivo Black, Creepster, Bangers | github.com/google/fonts (`ofl/`) |
| FredokaOne-Regular.ttf | instance statis Fredoka wght 600 (google/fonts `ofl/fredoka`), dinamai "Fredoka One" |
| Quicksand-Bold, Teko-SemiBold, Orbitron-Bold, RobotoMono-Bold | instance statis dari font variabel google/fonts (fontTools `instancer`) |

Font variabel diubah ke statis karena libass tidak bisa memilih bobot pada font variabel.
