Tab login Google akan terbuka. Kalau muncul "Google hasn't verified this app", klik Continue/Lanjutkan — itu aplikasi milikmu sendiri. Ganti client_secret.json
Kenapa tidak langsung muncul login? Google mewajibkan setiap aplikasi punya "OAuth client" sendiri. Login bawaan aplikasi Antigravity hanya berlaku untuk Antigravity, jadi Viral Auto Klip butuh client milikmu. Cukup sekali (±5 menit), setelah itu tinggal klik login.
  1. Buka Google Cloud Console → buat project (gratis).
  2. Aktifkan Generative Language API → klik Enable.
  3. Buka Google Auth Platform → Get started: isi nama app & email, Audience External. Di Audience → Test users tambahkan email Google kamu.
  4. Buka Clients → Create client → Application type Desktop app → Create → Download JSON.
  5. Pilih file JSON itu di bawah — login langsung terbuka.
Alternatif tanpa OAuth: ambil API key gratis di aistudio.google.com/apikey lalu pilih provider Gemini.

Riwayat job

Job di sesi server ini (disimpan 24 jam di memori server). Klik "Lihat" untuk membuka hasilnya.

Cara pakai

Dari video panjang ke klip siap upload dalam 5 langkah.

Jalankan aplikasi

Double-click start.bat di folder proyek. Pertama kali akan meng-install dependency & FFmpeg (beberapa menit), lalu browser terbuka otomatis ke http://localhost:8000/app. Biarkan jendela hitam (server) tetap terbuka selama dipakai.

Siapkan AI (sekali saja)

Buka .env dan isi API key provider yang kamu punya — cukup satu, mis. ANTHROPIC_API_KEY=… untuk Claude atau GROQ_API_KEY=… (ada tier gratis). Restart start.bat. Kamu juga bisa menempel key langsung di langkah 2 halaman ini (tidak disimpan).

  • Tanpa key? Pilih Ollama (AI lokal) atau matikan AI — klip tetap dibuat dengan scoring lokal.
  • Antigravity: login akun Google, butuh client_secret.json OAuth Desktop.
  • Custom: endpoint OpenAI-compatible apa pun — isi Base URL, key, dan nama model.

Tempel link & atur

Tempel URL video di langkah 1, pilih provider AI di langkah 2, lalu preset di langkah 3 (Seimbang cocok untuk kebanyakan video). Klik Tes koneksi untuk memastikan AI siap.

Klik "Buat klip viral"

Progres tampil per tahap: download → transkripsi → AI memilih momen → render → paket upload. Halaman boleh ditutup; buka lagi dan job dilanjutkan otomatis.

Review, download, upload

Tonton tiap klip langsung di halaman, salin caption per platform, download MP4. Upload otomatis ke YouTube Shorts / TikTok lewat tombol di hasil (butuh setup OAuth/cookies — lihat README). File juga ada di folder output/.

Tidak ada klip yang ditemukan?

Turunkan skor minimum (mis. 45) atau perlebar rentang durasi. Video tanpa banyak ucapan (musik/gameplay tanpa komentar) memang sulit dinilai.

Transkripsi lambat?

Pilih preset Cepat, model Whisper small, atau mesin cloud (Groq/ElevenLabs) di pengaturan lanjutan.

Error "belum dikonfigurasi" di AI?

Key untuk provider itu belum ada. Isi di .env atau tempel di kolom API key, lalu klik Tes koneksi. Nilai contoh seperti your_..._here dianggap kosong.

Video YouTube gagal didownload?

Beberapa video butuh login. Export cookies YouTube ke cookies.txt di folder proyek (YTDLP_COOKIES di .env), atau pakai Streamlit UI / CLI untuk upload file lokal.

Data saya dikirim ke mana?

Video diproses di komputer kamu. Bila AI aktif, transkrip dikirim ke provider AI yang dipilih; mode Groq/ElevenLabs mengirim audio. Untuk 100% lokal: Whisper lokal + Ollama.

Pengaturan

Disimpan ke file .env dan langsung berlaku tanpa restart. API key hanya ditampilkan tersamar.
